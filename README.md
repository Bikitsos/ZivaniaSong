# Zivania Night

A Cypriot tavern party tune written as live code with [Strudel](https://strudel.cc).

- **Key / scale:** D hijaz (phrygian dominant)
- **Tempo:** 100 BPM
- **Source:** [`ZivaniaNight.strudel`](./ZivaniaNight.strudel)
- **Audio:** the rendered WAV is attached to the [latest release](https://github.com/Bikitsos/ZivaniaSong/releases/latest)

## Arrangement

An 80-cycle loop that repeats:

| Section   | Cycles |
|-----------|--------|
| Intro     | 8      |
| Verse     | 16     |
| Breakdown | 8      |
| Build     | 16     |
| Party     | 24     |
| Outro     | 8      |

## Layers

- **Drums:** doumbek / tsifteteli groove on TR-808 sounds, plus extra percussion in the party section
- **Bass:** triangle drone on the root, walking to the 5th and 4th
- **Bouzouki:** tremolo-picked sawtooth melody
- **Baglama:** strummed offbeat chords
- **Lead:** clarinet/violin-like line with vibrato and delay, joining in the build
- **Response:** higher triangle line adding energy to the party section

## Play it

1. Open [strudel.cc](https://strudel.cc).
2. Paste the contents of `ZivaniaNight.strudel` into the editor.
3. Press `Ctrl+Enter` (or the play button) to start.
